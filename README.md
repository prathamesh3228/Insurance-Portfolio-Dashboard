# Insurance Portfolio Dashboard in Excel

## About the Project

This project is an **Insurance Portfolio Dashboard created using Microsoft Excel**. 
The dashboard analyzes insurance data for the **2023–2024 period** and presents important business insights using interactive charts, KPIs, and data visualizations.

The dashboard provides a clear overview of policies, premiums, claims, agents, risk levels, policy status, and regional performance.

##  Project Objective

The main objective of this project is to analyze insurance data and convert it into meaningful business insights using **Excel Dashboard and Data Visualization**.

This dashboard helps to:

- Analyze total policies
- Track total premium collection
- Analyze claims paid
- Calculate claims ratio
- Monitor approval rate
- Analyze monthly policy trends
- Compare policy types
- Analyze risk levels
- Compare agent performance
- Analyze claims by region
- Understand policy status
- Analyze claim occurrence

##  Dashboard Features

###  Monthly Policy Trend

Shows the number of policies generated each month and helps identify changes and trends throughout the year.

###  Average Premium vs Average Claim Amount

Compares the average premium and average claim amount across different insurance policy types:

- Auto
- Health
- Home
- Life
- Travel

### Total Policy by Risk

Shows the distribution of policies based on risk levels:

- Low Risk
- Medium Risk
- High Risk

### Claim by Region

Provides a regional analysis of claim amounts and helps understand which regions contribute more to the total claims.

### Total Premiums by Agents

Shows the total premium generated by each insurance agent and allows comparison of agent performance.

### Total Policy by Status

Displays policies according to their current status:

- No Claim
- Approved
- Rejected
- Pending

### Policy by Claim Occurrence

Shows the comparison between policies with claims and policies without claims.
